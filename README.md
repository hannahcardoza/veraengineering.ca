# veraengineering.ca

A static website for Vera Engineering: plain HTML and CSS, with no build step.

## Files

- `index.html`: the home page
- `styles.css`: the styles
- `vera-logo.svg`: the logo (V)
- `vera-logo-dot.svg`: the logo with a dot (V.)
- `favicon.svg`: the browser tab icon (the V. logo with extra space around it)
- `vera.jpeg`: the background photo

## Preview locally

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deploy

Upload these files to any static host, such as GitHub Pages, Netlify, Cloudflare Pages or Vercel.
